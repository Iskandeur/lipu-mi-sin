每个人只看到一个影子

对一个话题的看法，是一个永远无法被看全的物体投下的影子：扁平、残缺，形状由观看者所站的位置决定。别人看到的是别的影子。把这些影子拼在一起，才能猜出那个物体。这是一个拿来摆弄、而不是拿来相信的想法，附上让它站得住的理由，以及它失效的地方。

Alexandre Pinoteau23.10.20264 个可交互场景

01影子不会说谎，但它不会说出全部

一个物体，一盏灯，一面墙。影子不会凭空捏造：每一块暗区都对应着物体真实的一部分。但它丢掉了整整一个维度，而且它的形状既取决于物体本身，也同样取决于光线的角度。

观点也是这样运作的。在任何话题上（工作、金钱、爱情、整个人生），每个人看到的都是一个比自己更大的物体的投影。角度，就是各自的经历：一个国家、一份职业、一个家庭、一些伤痛、一些阅读。这不是推理上的缺陷，而是几何。没有人是从“无处”观看的。

02两个互相矛盾的影子

Ana 看着地面，看到一个圆盘。Ben 看着墙，看到一个正方形。两人的证据都摆在眼前，各自都可以骂对方瞎了眼，一骂就是好几年。

有两种本能反应很诱人，第三种才管用。第一种：判定谁对。第二种：各让一半，结果得到一个软塌塌、看似合理的形状，Ana 和 Ben 谁也没看到它，而且对两人来说它都是错的。第三种：去找哪个物体能同时投下这两个影子。他们俩都是对的，而他们之间的矛盾，恰恰就是缺失的那条信息：一种深度留下的痕迹，这种深度两人谁也无法独自看见。

03用减法来雕刻

影子说出的，主要是物体不是什么：凡是会超出影子的部分，都被排除了。所以先从一整块材料出发，每个目击者削去与自己所见不符的部分，剩下的就会接近那个物体。在计算机视觉中，这块被雕出来的东西叫作视觉外壳（visual hull）。医学 CT 扫描做的是同一件事，只是更精细，用的是围绕病人一圈拍下的 X 光片。

轮到你了

物体被藏起来了。你只有自己的影子（那个黄点）。点按圆环来添加目击者：边缘代表平视，中心代表从正上方往下看。试着在揭晓之前猜出这个物体。

这不是求平均。影子不投票，它施加约束：它不添加任何东西，只排除可能性。

这个比喻为什么站得住

  • 数学站在它这一边。1917 年，Johann Radon 证明：一个物体完全由它在所有角度下的 X 光投影所决定。CT 扫描仪所依据的正是这个结果（1979 年诺贝尔奖，Cormack 和 Hounsfield）。
  • X 光片胜过影子。影子是非黑即白的；X 光片却能说出光穿过了多少物质。一个有分寸的观点（“大多”“相对来说”“除非……”）比一句是或否携带更多信息，也更有助于重建。
  • 多样性比数量更重要。当一群人估计一个数字时，群体误差等于个体的平均误差减去他们估计值的多样性（Scott Page 的“多样性预测定理”）。相距遥远的角度，比数量众多的角度更有价值。
  • 它解释了分歧，而不必把任何人当成傻瓜。两个诚实而清醒的人可以互相矛盾，而谁都没有错。这个假设比“对方不是蠢就是不诚实”更宽厚，也更常常是对的。

04比喻失效的地方

一个找不到地方攻击的比喻，没多大价值。这个比喻有五处裂缝。前三处可以在上面的场景里亲手验证。

1. 一千个邻居，只抵一个目击者

十个邻居能让相似度提高几个百分点。一个陌生人往往就比这十个人加起来做得更好。起重建作用的不是观点的数量，而是角度之间的差距。一条信息流、一个朋友圈子、一个团队，常常把同一个影子反射回来一百次。同一个影子看上一百遍，只会让人更自信，而不会更正确。

2. 凹陷投不出影子

换成物体 3，无论有多少目击者，相似度都会卡在一个上限。它是一只杯子，而杯子的凹陷从任何角度看，都不会在轮廓上显露出来。更糟的是：一个实心圆柱体投下的影子一模一样。可以集齐所有外部视角，然后满怀信心地得出一个错误的物体。有些东西只能从内部看见：贫穷、生病、流亡、为人父母，究竟是什么滋味。外部的目击者再多，也重建不出这些。必须倾听身处其中的人。

3. 一个说谎者就够了

由于只保留所有影子都允许的部分，一个说谎者就会削掉真实的部分，而被他削掉的东西，再也没有什么能粘回去。调低信任度，就只保留多数影子认可的部分：说谎者不再有分量，但物体会变得臃肿，因为诚实的目击者带来的信息也被丢掉了一部分。不存在放之四海而皆准的设置：在轻信与充耳不闻之间，每个人都在选择自己愿意付出的代价。

4. 不知道别人从哪里看，也不知道自己从哪里看

在场景里，每个目击者的位置都精确到度。在生活中，却得去猜对方是站在什么位置说话，而每个人对自己的角度也知之甚少。冷冻电子显微镜碰到的是同一个问题：它要从成千上万张角度未知、充满噪声的图像中重建分子。这行得通，但有一个著名的陷阱，叫“Einstein from noise”（噪声里的爱因斯坦）：把一堆纯噪声图像对准一张爱因斯坦的肖像对齐，再取平均，爱因斯坦就出现了。透过自己的模型去解读别人影子的人，重建出来的……是自己的模型。

5. 如果根本没有物体呢？

整个比喻都假定外面有一个物体，对所有人都一样，在被观看时也不会移动。对于事实问题（气候、一场事故、一种疾病），这个假定是合理的。对于“整个人生”，它就是一场赌注。一个人生命的意义、滋味和价值，也许并不是被投下影子的物体，而是在一定程度上由目光造就的东西。而且，一个社会在被观看时就会改变。就连最后的重建，也存在于某个人的脑子里，而这个脑子有它自己的角度：不存在“来自无处的视角”。于是，这个比喻与其说是真理，不如说是一种自我约束：假装有一个物体，好继续寻找它，但不自称已经把它握在手中。

05可以留下些什么

  1. 去找离得最远的角度，而不是人数最多的角度。
  2. 面对矛盾，先问“什么物体能投下这两个影子？”，再问“谁错了？”。
  3. 问清对方从哪里看，也问问自己从哪里看。
  4. 给出理由，而不只是结论：宁做 X 光片，不做影子。
  5. 调好自己的信任度：高到足以让每个目击者都带来些新东西，又不至于让一个说谎者雕出整个物体。
  6. 记住那些凹陷：倾听从内部去看的人。

早有人说过，换了说法

  • 柏拉图的洞穴（《理想国》第七卷）：囚徒们只看得到影子。在柏拉图那里，得救之道是走出洞穴，去看那个物体本身。而在这里，谁也出不去：只有影子，只能把它们互相比较。
  • 盲人摸象，印度寓言：每个人摸到一部分，就把它当成了整体。耆那教由此发展出一种学说，anekāntavāda，即“非片面性”。
  • Gödel, Escher, Bach（《集异璧》）的封面（Hofstadter，1979）：一块雕刻出来的实体，它的影子分别构成 G、E、B 三个字母。
  • Thomas Nagel，The View from Nowhere（1986）：客观性是一种努力，努力摆脱自己的视角，而这种努力永远走不到终点。

本文也逃不过这一点。这里，文章的第一个场景变成了一个物体：放在一个房间里，它也投下了自己的影子。它的墙只剩一道线，它的物体只剩一团斑块，它的灯只剩一个点。每一张示意图都是某个想法的影子，而这篇文章也不过是又一个影子。

发现了第六处漏洞？非常欢迎：这正是本文所缺的那种影子。
