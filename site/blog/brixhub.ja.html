BrixHub：盗まれたあなたのデータの検索エンジン

あるサイトに名前を入力すると、住所、電話番号、社会保障番号が返ってきます。ハッキングで流出した140億件の記録を索引化していると言い、さらにあなたの記録を消すことを…料金と引き換えに持ちかけます。フランスの司法の標的になっているのに、今も公開されています。どうやって持ちこたえているのかを調べました。

これだけ読めば十分です

  1. 使わないでください。好奇心からでも、自分の名前を調べるためでも同じです。他人を調べると訴追される可能性があり、フランスの司法はこのサイトについて検察官に通報しています。
  2. 記録を消すためにお金を払わないでください。そして身分証明書を送らないでください。データを盗んだ側にお金を払い、さらに一つ余計にデータを渡すことになります。
  3. 自分の漏えいは、無料で安全に確認できます。haveibeenpwned.comは、データそのものを一切表示しない正規のサービスです。
  4. データが出回っているなら：重要なパスワードを変更し、2段階認証を有効にして、銀行口座を見守ってください。

BrixHubは検索エンジンです。ただしウェブページではなく、データ漏えいの中を探します。つまり、企業や行政機関へのハッキングで盗まれたファイルです。名前、電話番号、メールアドレスを入力すると、記録が一件返ってきます。140億件を超える記録があると謳っています。

2026年10月、フランスの報道がこれを取り上げ、デジタル担当大臣が司法に通報しました。これは何なのか、使ってよいのかと、多くの人が疑問に思っています。短く答えると、いいえ、絶対にいけません。理由と、この種のサイトの仕組みを説明します。

01このデータはどこから来るのか

本物の漏えいからです。ここ数年、フランスの多くの企業や機関が顧客ファイルを盗まれました。通信事業者、共済組合、通販サイト、公共サービスなどです。一つの漏えいごとに、何百万人もの名前、住所、電話番号、あるいはもっと重要な情報が外に出てしまいます。

BrixHubのようなサイトは、自分では何もハッキングしません。散らばったファイルを拾い集め、突き合わせ、ワンクリックで検索できるようにします。問題はまさにそこです。単発の漏えいは悪用しにくいものですが、名前、住所、電話番号、社会保障番号を一件の記録にまとめる検索エンジンは、嫌がらせ、なりすまし、詐欺のための武器になります。

ご注意

BrixHubは、公的機関の名前を情報源として誇らしげに掲げています。どの機関も確認しておらず、私はこの主張を取り上げません。これはサイト側の言い分であって、確立した事実ではありません。

02本当の商売：あなた自身の安心を売りつける

最も悪質なのは検索ではなく、「Suppression RGPD」というオプションです。サイトは、料金と引き換えに記録の削除を持ちかけます。証言によれば、数件の記録で数ユーロ程度です。ときには「無料」の削除もありますが、その代わりに身分証明書の写真を求められます。

罠の中の罠です

盗まれたデータを持っている相手にお金を払い、消すと約束してもらうのです。実際に消す保証はどこにもありません。さらに身分証明書を送れば、今度は完全に本物のデータをもう一つ渡すことになります。デジタル担当大臣は10月5日に公にこう述べました。「データを消すために、決してお金を払わないでください」（AFP）。つまり：払わない、何も送らないということです。

これは単なる理屈上の注意ではありません。X（旧Twitter）では、お金を払って記録を消してもらったという人たちが、記録は確かに消えたが…数日後に再び現れたと書いています。当然です。表示から一行を消しても、運営者が持っている盗まれたファイルからデータが消えるわけではありません。運営者はそれを再び公開することも、転売することも、また料金を請求することもできます。

03なぜ閉鎖されないのか

このようなサイトを閉鎖するのは、見かけよりずっと難しいからです。BrixHubは3つの手を使います。

  1. 目隠しの衝立

    サイトは、本当のサーバーのアドレスを隠す技術的な仲介者（Cloudflare）の後ろに隠れています。見えるのは正面だけで、建物は見えません。

  2. 使い捨てのアドレス

    ドメイン名が一つブロックされるたびに、別のものに乗り換えます。.fun、.net、.site、.org、.cc、そして.to、.ru、.st…。一つの扉が閉まっても、別の扉がすでに開いています。

  3. 協力的でない国々

    小さな国が管理する拡張子（.stはサントメ・プリンシペ、.toはトンガ）を選びます。こうした国は内容を監視せず、裁判所の決定があったときしか動きません。

その結果、ワンクリックで潰すことはできません。一般に、こうしたサイトを倒すのはドメインの閉鎖ではなく、運営している人たちの逮捕です。そして、それには時間がかかります。

04法律は何と言っているか

私は法律家ではありませんが、資料から読み取れることは次のとおりです。

  • サイトを見ること自体は、特定された犯罪ではありません。
  • 一方、他人を調べ、その結果を保管、共有、利用すると、現実のリスクを負います。盗品等関与、不公正なデータ収集、特定の人物を狙えば嫌がらせやなりすましにも当たりえます。
  • サイトを運営すること（運営している人たち）は、データへの不正アクセスと不正抽出にあたります。数年の懲役と高額の罰金です。

2026年10月5日、デジタル担当大臣はパリの検察官に通報しました。あちこちで繰り返されたその助言は、「データを消すために、決してお金を払わないでください」です。

あなたも彼らのファイルにあるかもしれません。どうすればよいか

  1. BrixHubで確認しないでください。haveibeenpwned.comを使います（メールアドレスを入力すると、既知のどの漏えいに含まれているかを教えてくれます）。
  2. 関係するアカウントのパスワードを変更し、あらゆるところで2段階認証を有効にします。
  3. 狙い撃ちの詐欺に注意してください。これらのデータがあれば、銀行や公共サービスを装って連絡できます。迷ったら電話を切り、公式の番号にかけ直してください。
  4. あなたの記録が公開されている場合：自分の記録だけのスクリーンショットを証拠として保管し、通報し、動きがなければCNIL（フランスの情報保護機関）に申し立てます。お金は払わないでください。

共有してください

多くの人が、それが悪い考えだと知らずに「ただ自分の名前を確認する」だけのつもりで使おうとします。知らせてあげてください。

  • BrixHub：フランス語圏の、漏えいデータの検索エンジン。約145億件の記録を謳い、記録の削除を販売しています。2026年10月5日にパリの検察官へ通報されました（刑事訴訟法第40条）。
  • 約12のTLDにまたがるドメインのローテーションが2026年2月から続いています：.fun → .net → .site → .org → .cc → .to → .ru → .st。10月21日時点で3つが稼働中（.to、.ru、.st）で、Cloudflareの同じNSのペアを使っています。
  • ウェブのオリジンは暴かれていません（すべてCloudflareの背後）。CDNの外にある唯一のインフラは、専用のメールサーバー195.58.146[.]225（M247）で、3つのドメインは郵便をここに委任しています。

  • 受動的な調査（Bounce + urlscan + 報道）。何も入力しておらず、通常のブラウザ以上のサービスへのリクエストもなく、帰属は行っていません。

01背景と方法

BrixHubはフランス語の「漏えい検索エンジン」（data leak search engine）です。侵害によって得られたデータベースを索引化し、氏名での検索と、有料の記録削除を提供しています。フランスでは2026年10月5日から、刑事上の通報の対象になっています。出発点の問いは単純でした。そのAPIを使えるのか。この調査がそれに答えます。

交戦規則

受動的な公開ソース：レジストリのWHOIS/RDAP、DNS、Certificate Transparency、urlscan.io、VirusTotal、Shodan/InternetDB、パッシブDNS、報道。最初の調査はCTIエージェントBounceで行い、手作業で補いました。サービスにログインしたことはなく、検索も一度も実行せず、いかなる保護も回避していません（ブラウザを使わないクライアントには、ページはCloudflareの403チャレンジを返し、これは回避していません）。ドメインはデファングしています（[.]）。

02サービスが主張していること

サイト自身のページと報道によるもの（数字は事実ではなく、主張として受け取ってください）。

145億主張されている記録数（トップページのカウンター）
約5ユーロ10件の記録を削除する料金（証言による）
10〜90ユーロサブスクリプション、「月額」から「永久」まで
12以上2026年2月から続いたドメイン

氏名、メールアドレス、電話番号、Discord識別子で検索でき、データはNIR（社会保障番号）やIBANまで含むとされ、対象はフランス、ベルギー、スイスです。「家系図」タブ、「キー不要でIP制限付きのオープンAPI」（当初の問いへの答えはこれです。APIが表示されており、使うことは盗まれたデータを承知で抽出することに当たります）、Telegramボット、Xのアカウントもあります。法的表示には「ロシアに拠点を置く会社」とありますが、名前はありません。これらの主張は外部からはどれも検証できず、私は事実として扱いません。

03インフラ：正面だけで、建物はない

ウェブはすべて、稼働中の3つのドメインでCloudflareの背後にあります。オリジンは一度も漏れていません。共有されたフィンガープリントが、同一の運営者であることを裏づけています。

3つのマーカーが稼働中のドメインを結びつけています。Cloudflareの同じネームサーバーのペア（irena / weston）、同じSPFポリシー（v=spf1 mx:brixhub[.]to -all）、そして同じページタイトルです。.stは9月30日に生まれており、大臣の通報の5日前です。

唯一の漏えい：メールサーバー

ウェブのオリジンは隠されていますが、メールは隠されていません。3つのドメインは、メール（MXとSPF）をmail.brixhub[.]toに委任しており、これはCloudflareの外にあるIPに名前解決されます。

mail.brixhub[.]to → 195.58.146[.]225 AS9009 M247 · ptr mail.brixhub.to Postfix + OpenSSH 9.6p1 · Ubuntu 24.04 cert SMTP auto-signé, CN=mail.brixhub.to (04/10/2026, valide 10 ans) pas d'autre domaine observé sur cette IP en DNS passif

これは、調査が明らかにした、運営者に固有の唯一のインフラ上の点です。ウェブサイト（別の場所に置かれ、Cloudflareの背後にある）を「暴く」わけではありませんが、堅実なピボットです。専用のIP、名前のあるホスティング会社、日付のある証明書。Bounce自身も自己批判の中でこう記していました。この「mail」のIPは、最も興味深い拡充の対象であり、運営者の構成の弱点だと。

04なぜオンラインに残っているのか

BrixHubの耐障害性は偶然ではありません。4つの選択に支えられています。

  • Cloudflareのフロント。本当のホスティング会社を隠し、不正利用の通報を吸収します。
  • 多様なTLDにわたるドメインのローテーション。従来のgTLD（.fun、.cc、.site、.org）は、6月から8月の間にレジストラによって停止されました。運営者は、そのたびにより協力的なccTLDへ移りました。
  • 協力度の低いレジストリ。.stのレジストリ（サントメ、バックエンドはスウェーデン）は、ポリシーで「内容を監視しない」と明記し、管轄の裁判所の決定があるときにしかドメインを取り消しません。.to（トンガ、運営はTonic）も同様の評判ですが、裁判所の命令でドメインを停止したことはあります。
  • 退避用のチャネル。Telegramボットが切り替えのたびに新しいアドレスを知らせ、メールは何があっても.toに固定されています。サービスは、どのドメインを失っても生き延びます。

言い換えれば、こうしたサービスを倒すのはドメインの差し押さえではなく、運営者の身柄の確保です。前例がそれを示しています。WeLeakInfo（2020年に差し押さえ）、RaidForums（2022年）、BreachForumsの管理者（2025年にフランスで逮捕）、そして2026年に逮捕を伴って解体された複数のフランスの「lookup」サービス。いずれも、技術的なブロックではなく司法捜査によるものです。

05合法か。そのAPIを使えるか

いいえ、そして、いいえ。法的な整理です（弁護士の分析と報道によるもので、私は法律家ではありません）。

立場問題になること
運営者データへの不正アクセスと不正抽出（刑法第323-1条以下）。数年の懲役と高額の罰金に至りうる。
利用者閲覧自体は特定された犯罪ではありません。しかし、第三者を検索し、その結果を保有、共有、利用すれば、盗品等関与（第321-1条）、不公正な収集（226-18）、さらには嫌がらせやなりすまし（223-1-1）の責任を負いえます。支払いや身分証明書の送付は、リスクを悪化させます。
API盗まれたデータベースへの自動アクセスは、意図的かつ大規模な抽出です。しかも、恐喝サービスに資金を与えます。避けるべきです。

破毀院は2026年2月に、無体の情報も盗品等関与の対象になりうると認めています。事案は営業秘密に関するもので、データ漏えいではありませんが、この原則は、これらのデータを「使う」ことにリスクがないという考えを揺るがします。

正しい代替手段

自分自身の漏えいを、誰にも資金を出さず、誰も利することなく確認するには：Have I Been Pwned。あなたのメールアドレスが既知のどの漏えいに含まれているかを教えてくれ、データそのものは決して表示しません。BrixHubに対する、合法な対極の例です。

06この調査が決着をつけていないこと

誠実さのために、限界を記します。

  • サイトの本当のホスティング会社と運営者の身元：隠されています。受動的なソースだけでは、帰属できるものは何もありません。
  • データの本当の出どころ：サイトは立派な情報源（公的機関）を掲げていますが、確認されたものはありません。私はこの主張を取り上げません。
  • 正確な金額や、APIとサブスクリプションが実在するかどうかは、二次的な証言に基づいています。料金を払ったのに再び現れた記録も同じです。Xでのネットユーザーの証言で、サービスの仕組みとは整合しますが、一件ずつは検証できませんでした。
  • 複数の報道記事（franceinfo、Le Monde、Siècle Digitalなど）は、全文を読めず、見出しと抜粋しか確認できませんでした。
