BrixHub：专查你被盗数据的搜索引擎

有个网站，输入你的名字，就吐出你的住址、电话、社保号。它自称索引了 140 亿条来自黑客攻击的记录。然后它提议帮你删掉自己的那一条……要付钱。它已被法国司法部门盯上，却依然在线。我看了看它是怎么撑住的。

只读这一段也行

  1. 不要使用它，哪怕出于好奇，哪怕只是搜自己的名字。搜别人可能让你面临追责，而法国司法部门已就这个网站向检察官提交了案件。
  2. 千万别付钱删除你的记录，也千万别发送你的身份证件。你付钱给的，正是持有你被盗数据的人，还会再多给他们一份你的资料。

  4. 如果你的数据已经流出：修改重要密码，开启双重验证，留意你的银行账户。

BrixHub 是一个搜索引擎。但它搜的不是网页，而是数据泄露：企业和政府机构被黑客攻击时被盗走的文件。你输入姓名、电话或电子邮箱，它就返回一条记录。它声称有超过 140 亿条记录。

2026 年 10 月，法国媒体纷纷报道，数字事务部长也向司法机关提交了案件。很多人想知道这是什么，能不能用。简短的回答：不能，千万别用。下面是原因，以及这类网站是怎么运作的。

01这些数据从哪来？

来自真实的泄露。近几年，大量法国企业和机构的客户文件被盗：电信运营商、互助保险公司、电商网站、公共服务部门。每一次泄露，都意味着数百万人的姓名、住址、电话，甚至更多信息流落在外。

像 BrixHub 这样的网站自己并不攻击任何人。它只是收集这些散落的文件，交叉比对，再让它们一键即可查询。问题恰恰在这里：单独一次泄露很难利用，但一个把你的姓名、住址、电话和社保号合在同一条记录里的搜索引擎，就是骚扰、冒用身份和诈骗的武器。

需要注意

BrixHub 很自豪地列出一些公共机构的名字作为数据来源。没有一家确认过，我也不采信这些说法：那是它自己的说辞，不是已证实的事实。

02真正的生意：把你自己的安宁卖给你

最恶劣的不是搜索，而是“GDPR 删除”这个选项。网站提议，付费即可删除你的记录。据一些说法，一小批记录大约要几欧元。有时则是“免费”删除……条件是给一张你身份证件的照片。

圈套里还有圈套

你付钱给的，是持有你被盗数据的人，只为让他们承诺删掉。没有任何东西保证他们真的会删。而如果你发送了身份证件，你就多给了他们一份数据，而且这次是完全真实的。数字事务部长在 10 月 5 日公开说过：“不要为删除你的数据付钱”（AFP）。所以：不要付钱，什么也别发。

这也不只是纸上谈兵的提醒。在 X（原 Twitter）上，有网友说自己付钱删除了记录：确实消失了……几天后又重新出现。这很正常：从显示页面里抹掉一行，并不会让被盗文件中的数据消失，文件还在运营者手里。他可以把它重新上线、转卖，或者让你再付一次钱。

03为什么还没被关掉？

因为关掉这样一个网站，比看上去难得多。BrixHub 玩的是三手准备：

  1. 一道屏风

    网站躲在一个技术中介（Cloudflare）后面，它隐藏了真实服务器的地址。你看到的是门面，看不到房子。

  2. 用完即弃的地址

    一个域名被封，它就换一个：.fun、.net、.site、.org、.cc，然后是 .to、.ru、.st……一扇门关上，另一扇已经开着。

  3. 睁一只眼闭一只眼的国家

    它选择由小国管理的后缀（.st 属圣多美，.to 属汤加），这些地方不监控内容，只在法院裁决后才行动。

结果是：不能一键把它搞垮。通常让这类网站倒下的，不是域名被关，而是运营它们的人被逮捕。而这需要时间。

04法律怎么说

我不是法律人员，但从资料来看是这样：

  • 浏览这个网站本身，并不构成已确定的违法行为。
  • 搜索别人，然后保存、分享或使用结果，则会让你面临真实的风险：窝藏赃物、不正当收集数据，如果针对某个人，甚至构成骚扰或冒用身份。
  • 运营这个网站（即让它运转的人）属于非法访问和非法提取数据：数年监禁和高额罚款。

01背景与方法

BrixHub 是一个法语的“泄露搜索引擎”（data leak search engine）。它索引来自入侵事件的数据库，提供按姓名检索，外加付费删除记录。自 2026 年 10 月 5 日起，它在法国面临刑事举报。出发点的问题很简单：能用它的 API 吗？这次调查回答了这个问题。

行动规则

公开的被动来源：注册局的 WHOIS/RDAP、DNS、Certificate Transparency、urlscan.io、VirusTotal、Shodan/InternetDB、被动 DNS、媒体。第一轮由 CTI 代理 Bounce 完成，再由人工补充。我从未登录该服务，没有在上面发起任何搜索，也没有绕过任何防护（对没有浏览器的客户端，页面返回 Cloudflare 403 挑战，未绕过）。域名已去武器化处理（[.]）。

02服务自称的内容

依据它自己的页面和媒体报道（这些数字只能当作声称，而非事实）：

145 亿条声称的记录（首页计数器）
~5 €删除 10 条记录，据网友说法
10→90 €订阅，从“每月”到“终身”
12+2026 年 2 月以来相继使用的域名

可按姓名、电子邮箱、电话、Discord 标识搜索；声称的数据最多到 NIR 和 IBAN；覆盖法国、比利时、瑞士。有“家谱”选项卡，有一个“开放 API，无需密钥，按 IP 限流”（这就是对最初那个问题的回答：它展示了一个 API，而使用它等于明知故犯地提取被盗数据），有 Telegram 机器人和一个 X 账号。法律声明提到一家“总部在俄罗斯的公司”，没有名称。这些说法没有一条能从外部验证，我也不视其为既定事实。

03基础设施：只有门面，没有房子

三个在用域名的整个 Web 都在 Cloudflare 之后。源站从未泄露。共享的指纹证实是同一个运营者：

三个标记把在用域名联系在一起：同一对 Cloudflare 域名服务器（irena / weston）、同一条 SPF 策略（v=spf1 mx:brixhub[.]to -all）和同一个页面标题。.st 诞生于 30/09，比部长报案早五天。

唯一的泄露：邮件服务器

Web 源站被隐藏了，但邮件没有。三个域名都把邮件（MX 和 SPF）委派给 mail.brixhub[.]to，它解析到一个不在 Cloudflare 的 IP：

mail.brixhub[.]to → 195.58.146[.]225 AS9009 M247 · ptr mail.brixhub.to Postfix + OpenSSH 9.6p1 · Ubuntu 24.04 SMTP 证书为自签名，CN=mail.brixhub.to（04/10/2026，有效期 10 年） 被动 DNS 中未在该 IP 上观察到其他域名

这是调查暴露出的、唯一属于运营者自己的基础设施节点。它并没有“揭开”网站本身的面具（网站托管在别处，躲在 Cloudflare 后面），但它是个扎实的枢轴：一个专用 IP、一个有名字的托管商、一张有日期的证书。Bounce 自己在自我批评中也指出：这个“邮件”IP 是最值得深入富化的目标，也是运营者配置里的薄弱点。

04为什么它还在线

BrixHub 的韧性并非偶然。它建立在四个选择上：

  • Cloudflare 前端，隐藏真实托管商，并吸收滥用举报。
  • 跨多种顶级域的域名轮换。传统 gTLD（.fun、.cc、.site、.org）在 6 月至 8 月间被注册商暂停；每一次，运营者都迁移到更好说话的 ccTLD。
  • 低配合度的注册局。.st 的注册局（圣多美，后端在瑞典）在其政策中写明“不监控内容”，只有在有管辖权的法院裁决后才会取消域名。.to（汤加，运营方 Tonic）名声类似，不过它也曾在司法命令下暂停过域名。
  • 后备渠道。每次切换，Telegram 机器人都会公布新地址，而邮件无论如何都固定在 .to 上。无论失去哪个域名，服务都能存活。

换句话说：让这类服务倒下的不是查封域名，而是拘捕运营者。先例说明了这一点：WeLeakInfo（2020 年被查封）、RaidForums（2022）、BreachForums 的管理员（2025 年在法国被捕），以及 2026 年被取缔并伴有拘捕的数个法国“lookup”网站。每一次，靠的是司法调查，而不是技术封锁。

05合法吗？能用他们的 API 吗？

不合法，也不能。法律综述（依据律师的分析和媒体；我不是法律人员）：

方面涉及什么
运营者非法访问和非法提取数据（刑法典第 323-1 条及以下），最高数年监禁和高额罚款。
用户单纯查看本身不是已确定的违法行为。但搜索第三方后持有、分享或使用结果，则面临窝藏赃物（第 321-1 条）、不正当收集（226-18）乃至骚扰或冒用身份（223-1-1）。付款或发送身份证件会加重风险。
API对被盗数据库的自动化访问，属于有意的、大规模的提取。而且资助了一项勒索服务。应当杜绝。

此外，最高法院在 2026 年 2 月承认无形信息可以被窝藏。该案涉及商业秘密而非数据泄露，但这一原则削弱了“使用”这些数据没有风险的想法。

更好的替代方案

要检查你自己的泄露情况，又不资助、不养肥任何人：Have I Been Pwned。它告诉你电子邮箱出现在哪些已知泄露中，而且从不显示数据本身。它是 BrixHub 的合法反面例子。

06这次调查没能回答的

出于诚实，列出局限：

  • 网站的真实托管商和运营者的身份：被隐藏。仅靠被动来源，没有任何可以归因的东西。
  • 数据的真实来源：网站列出了显赫的来源（公共机构），没有一个得到证实。我不采信这些说法。
  • 确切金额，以及 API 和订阅是否真实存在，都依赖二手说法。付费后又重新出现的记录也一样：那是网友在 X 上的证词，与服务的运作方式吻合，但我无法逐一核实。
  • 若干新闻报道（franceinfo、Le Monde、Siècle Digital……）未能读到全文，只看到了标题和摘要。
