# Pack de publication — stories WhatsApp

Ton : prévention d'abord. « Vous avez reçu ça ? C'est une arnaque. Si vous êtes curieux, voilà plus d'infos. »

Liens (en ligne) :
- Arnaque au vote → https://alexandre-pinoteau.fr/blog/arnaque-vote-whatsapp.html
- BrixHub → https://alexandre-pinoteau.fr/blog/brixhub.html

## Comment poster

1. WhatsApp → Statut → ajoute l'image (`story-vote.png` ou `story-brixhub.png`, format 1080×1920).
2. Dans la légende, colle un des textes ci-dessous. Le lien est cliquable dans la légende d'un statut.
3. Si le lien passe mal sous l'image : poste un 2ᵉ statut juste après, en texte, avec le lien seul.
